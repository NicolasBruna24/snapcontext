## 2. Modelo de seguridad consolidado

Modelo **de las superficies auditadas en B9.61**. No es una garantía absoluta
fuera de ese alcance: describe las cadenas verificadas por A, B, C y D.

```text
HTTP  → Authentication → Capability → Input Validation → Filesystem / Action
WS    → Authentication → Capability → Action
WEBHOOK → Provider Authentication → Event Validation → Task Policy
        → TaskSecurityContext → Worker Revalidation → Allowed Action
REMOTE EXECUTION → EXECUTE_REMOTE → Remote Policy → Command Identity
                 → shell=False → Allowlist
TASK ROTATION → Generation → Pending Task → Cancellation → Worker Revalidation
```

Las capas son responsabilidades **distintas**; ninguna asume una validación
que otra no garantice.

| Capa | Dónde vive | Garantiza |
| --- | --- | --- |
| Authentication | `web/seguridad.py` | credencial del gateway (`compare_digest`, 0600, fail-closed) |
| Authorization | `web/app.py: CAPABILITY_MAP` + `_protector` + `MiddlewareSeguridad` | superficie → 1 capability; sin entrada ⇒ DENY |
| Filesystem | `web/filesystem.py: Frontera` | forma → realpath → containment → operación |
| Remote policy | `web/remota.py` | `EXECUTE_REMOTE` = DENY ALL; allowlist vacía en M1 |
| Plugin origin | `web/app.py: LocalPath \| RemoteURL` | esquema explícito, sin degradación |
| Task policy | `task_queue.py: TIPOS_PERMITIDOS` + `TaskSecurityContext` | tipo + contexto congelado + revalidación |

## 3. B9.61-D — Consolidación (Webhook ↔ Task Queue ↔ Execution)

La auditoría **B9.61-D** detectó que la cola de tareas y los gateways de
webhook no participaban en el modelo: un webhook de GitHub sin secreto
configurado era aceptado (fail-open) y encolaba un tipo `tests` que el worker
convertía en `git checkout {rama} && pytest` con `shell=True`. Cadena:

```text
RED → WEBHOOK (sin auth) → TASK_QUEUE → SHELL → ARBITRARY COMMAND
```

**B9.61-D-CORRECTION** la cerró por eliminación estructural, no por mitigación:

- **D-01** — el webhook falla cerrado sin secreto (`503`); con secreto, la firma
  es obligatoria (`401`); las referencias Git se **rechazan** (no se sanean)
  y el sink de shell se eliminó del código.
- **D-02** — `TaskSecurityContext` inmutable (owner / workspace_root /
  capabilities / policy / generación / origen), congelado en `encolar_tarea` y
  revalidado por el worker; `query`/`plan` como únicos tipos ejecutables, sin
  rama `else` ejecutable.
- **D-03** — la rotación avanza la generación y marca las tareas no terminales
  como `cancelada-por-rotacion`; el worker revalida la generación.

**B9.61-D-R** (auditoría independiente) concluyó
`PASS — SECURITY BASELINE CONSOLIDATED`, sin P0/P1 nuevos.
