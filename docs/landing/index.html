Asistente de IA agéntico con contexto automático para desarrollo: Graph RAG, planificador multi-archivo, sandbox seguro y multi-proveedor.

Instalar GitHub ⭐
PyPI: pip install snapcontext · VS Code · JetBrains · 7+ proveedores

¿Por qué SnapContext?

🧠 Graph RAG real

Indexa tu repositorio como un grafo de símbolos en segundo plano y degrada elegantemente a regex/LSP si algo falla. Nunca espera.

🔀 Multi-proveedor

Claude, Gemini, OpenAI, DeepSeek, Groq, Ollama local e incluso Intel Arc (XPU/Battlemage) con IPEX-LLM. Con perfiles de prompt optimizados por modelo.

🛡️ Seguridad de primera

Sandbox Docker, permisos por acción, shell=False y validación de rutas. Tus claves jamás salen del equipo.

🤖 Capacidad agéntica

Bucle ReAct, planificador JSON, multi-agente en paralelo y sub-agentes. De la pregunta al PR.

🔌 Herramientas y MCP

Editar código, ejecutar tests, consultar BDs, navegador y GitHub — con hooks y marketplace de skills.

🚀 Rápido desde el primer comando

Indexación en background: el CLI arranca al instante, con resultados parciales mientras el grafo se construye.

Instalación

# CLI (Python 3.10+)
pip install snapcontext

# Extensión VS Code (Marketplace)
# Busca "SnapContext AI" en el panel de extensiones.

# Con soporte Intel Arc (opcional)
pip install "snapcontext[xpu]"
# Configura tu proveedor en un minuto
snapcontext --init

# Primera consulta
snapcontext "revisa el login y corrige el bug de validación"

Casos de uso

  • Refactor multi-archivo: el planificador divide la tarea, los agentes editan en paralelo y los tests validan.
  • Onboarding a un repo nuevo: el Graph RAG responde "¿dónde se valida X?" en segundos, sin abrir 40 archivos.
  • Desarrollo 100% local: Ollama o Intel Arc B70 — cero coste por token, cero datos en la nube.
  • QA automático: detector de tests + sandbox ejecuta la batería y corrige fallos iterando.
