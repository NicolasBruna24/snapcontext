⚡ SnapContext
Asistente de IA para desarrollo con contexto automático.
No hace falta decirle qué archivos abrir — él los encuentra por ti.
✅ v0.4.0 📦 PyPI ⚡ Open Source 🐍 Python 3.9+ 🤖 Gemini · Ollama · DeepSeek · Groq

🚀 Instalación rápida

Instala SnapContext con un solo comando:

curl -LsSf https://NicolasBruna24.github.io/snapcontext/install.sh | sh

O, si prefieres pip:

pip install snapcontext
📖 Ver documentación 🐙 GitHub

✨ Características

🧠 Contexto automático Escanea tu repositorio y selecciona los archivos relevantes sin que tengas que hacer `/add`.
🤖 Múltiples proveedores Usa Gemini, Ollama local, DeepSeek o Groq para elegir los archivos más adecuados.
🔁 Bucle agéntico Prueba automática con `flutter test` o lanza el servidor con `flutter run` y corrige errores.
🛠️ Modo experto Revisa, añade o elimina archivos manualmente antes de ejecutar Aider.
⚡ Integración con Aider Usa la potencia de Aider para editar código con diffs precisos y commits automáticos.
📦 Instalación one-liner Instala en segundos con `curl | sh` o `pip install snapcontext`.

📌 Ejemplo

$ snapcontext "el botón de pago no funciona" ℹ Repositorio: C:\...\marketplace-productos-locales ℹ Escaneando el repositorio... ℹ 24 candidato(s) relevante(s). ℹ Seleccionando con Gemini... ✔ Archivos seleccionados (3): • lib/pages/pago/pago_page.dart • lib/models/pedido.dart • supabase/functions/procesar-pago-mp/index.ts ℹ Ejecutando Aider... ✔ Aider terminó correctamente.
